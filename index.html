Software Board

The top 100 new software of the last 12 months, plus an all-time top 100, ranked by GitHub stars, Steam players right now, or Apple App Store chart position. Pick a source, choose when it launched (1, 2, 3, 6 or 12 months, which shows that period’s items from the year’s top 100, or All for all time), switch between tiles and rows, and sort by ranking or newest.

Layout Sort

Data from the free, keyless GitHub REST API, Steam charts and store APIs, and Apple’s iTunes feeds and lookup API. Rank is the position in the top 100 for the last 12 months, so a 1 month view can show items like #34 or #71. All is the all-time top 100 for that source, whatever the launch date. GitHub date is the repository creation date, which is not always when the software first shipped. Steam “Most Played” is players in game at the last update, and only games on Steam’s Most Played chart (top 100) are listed, so the 1 to 12 month views only show recent games that are already on that chart. Apple ranking is the position in the US Top Free Apps chart; only apps that are in the chart can appear. GitHub, Steam and Apple are not affiliated with this site.
