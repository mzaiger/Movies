Software Board

The top 100 new software in each window, ranked by GitHub stars, Steam players right now, or Apple App Store chart position. Pick a source, choose how far back to look by launch date (1 to 12 months, or All for the all-time top 100), switch between tiles and rows, and sort by ranking or newest.

Data from the free, keyless GitHub REST API, Steam charts and store APIs, and Apple’s iTunes feeds and lookup API. All is the all-time top 100 for that source, whatever the launch date. GitHub date is the repository creation date, which is not always when the software first shipped. Steam “Most Played” is players in game at the last update. Apple ranking is the position in the US Top Free Apps chart; only apps that are in the chart can appear. GitHub, Steam and Apple are not affiliated with this site.
